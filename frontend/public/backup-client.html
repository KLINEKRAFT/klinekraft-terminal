KLINEKRAFT TERMINAL

Klinekraft Deck Backups

A personal Raspberry Pi backup integration for Klinekraft Terminal. It saves encrypted recovery data to the owner's Google Drive using restic and rclone.

Authorization takes place through Google. The dedicated backup client requests access only to files it creates or files explicitly shared with that app. Backup and restore jobs run on the owner's computer.

This informational website does not sign you in, collect backup files, or receive your recovery password.
