Backup privacy policy

This policy describes the dedicated Klinekraft Deck Backups Google Drive integration, a personal backup tool running on the owner's Raspberry Pi. It does not describe unrelated Terminal features or third-party services.

Data and purpose

The integration uses Google authorization to create, list, read and manage its backup files in the owner's Drive. It requests the drive.file permission: files created by the app or explicitly made available to it, rather than general access to all Drive contents. Google user data is used to provide the requested backup and restore functionality.

Daily backup payloads can include the Terminal database, saved research documents, game saves and settings, received files, and power preferences. A separately requested system recovery backup has a broader file scope. Restic encrypts backup contents before they are uploaded. Google receives the encrypted files and the connection and file metadata needed to store them.

Storage and sharing

OAuth tokens and client credentials are stored locally in private configuration files on the owner's computer. The recovery password is maintained separately from the uploaded backup repository. The backup integration does not send backup contents to an AI provider, sell Google user data, or use it for advertising. There is no separate Klinekraft cloud service receiving the backups.

This public information page does not request Google authorization or accept backup uploads. Its hosting provider may process ordinary website request logs. Google Drive and the website host operate under their own privacy policies.

Retention and control

Backups remain in the owner's Drive until removed through the backup tools or Drive. Revoking the app's access prevents future authorized operations but does not itself delete existing backup files or local copies. The owner can stop scheduled backups on the Pi, revoke access in Google Account settings, and remove backup files from Drive. Drive's own trash and retention behavior still applies.

Contact

For project support, use the Klinekraft Terminal issue tracker. Do not post credentials, recovery passwords, personal files or private backup contents in a public issue.
